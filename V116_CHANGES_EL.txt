ARIA ORIGINAL V116 — ΔΙΟΡΘΩΣΕΙΣ

1. Τοπικός llama-server:
   - Δεν χρησιμοποιεί πλέον σταθερά τη θύρα 8080.
   - Ελέγχει ελεύθερη loopback θύρα στην περιοχή 18080–18120.
   - Καταγράφει κάθε κατειλημμένη θύρα και την επιλεγμένη θύρα.
   - Όλα τα health checks και τα inference requests χρησιμοποιούν την ίδια δυναμική θύρα.
   - Η πλήρης αυτοδιάγνωση εμφανίζει την ενεργή θύρα και το πραγματικό αποτέλεσμα του server.

2. Online Backend:
   - Η πλήρης αυτοδιάγνωση ελέγχει απευθείας το https://aria-original-backend.onrender.com/health και εμφανίζει HTTP status και ασφαλές σύντομο body.
   - Το μήνυμα HTTP 404 αναφέρει την αποτυχημένη διαδρομή και ότι απαιτείται δημοσίευση του root render.yaml.
   - Το root render.yaml ορίζει rootDir BACKEND και Dockerfile ./Dockerfile.

3. Λογαριασμός:
   - Το πεδίο email εμφανίζει παράδειγμα silena@eimail.com.
   - Εγγραφή δημιουργεί λογαριασμό και ακολουθεί ξεχωριστή σύνδεση.

Σημαντικό:
- Η επιλογή ελεύθερης θύρας αντιμετωπίζει πιθανή σύγκρουση στη θύρα 8080, αλλά απαιτείται runtime δοκιμή στο Android για επιβεβαίωση.
- Το Backend δεν μπορεί να δημοσιευτεί από αυτό το περιβάλλον χωρίς πρόσβαση στον λογαριασμό Render του ιδιοκτήτη. Η εφαρμογή θα συνεχίσει να λαμβάνει 404 μέχρι να γίνει Deploy το Blueprint και να επιστρέφει HTTP 200 στο /health.
